## Локальная демонстрация DaData

Анкета работает без токена: при вводе БИК используется встроенный демонстрационный справочник. Если нужно проверить запрос к DaData, откройте `questionnaire/index.html`, выполните в консоли браузера `sessionStorage.setItem('dadataToken', 'ВАШ_ТОКЕН')` и обновите страницу. Токен хранится только в текущей сессии браузера, не записывается в файлы проекта и не отправляется вместе с анкетой. После демонстрации его можно удалить командой `sessionStorage.removeItem('dadataToken')`.
