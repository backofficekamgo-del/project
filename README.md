## Локальная демонстрация DaData

Анкета работает без токена: при вводе БИК используется встроенный демонстрационный справочник. Для тестового проекта токен сохраняется в `localStorage` этого браузера через блок настройки на странице. Для рабочего запуска токен нужно перенести на сервер, потому что в публичной странице он доступен посетителям.
